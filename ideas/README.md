## 实验准入模板

每个新 idea 在训练前必须写清：

1. 使用的官方资产 ID（O1-O6）和是否含 D/T/E 数据。
2. 对照实验及唯一变量。
3. 预计提升的 8 个子项之一，不接受只写“总分上涨”。
4. 训练 epoch 数、学习率日程、有效 batch、每轮更新步数和数据占比，以及选择训练时点的依据。
5. 失败停止条件、门禁项目和是否值得消耗线上配额。
