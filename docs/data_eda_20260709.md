# 官方数据侧 EDA(2026-07-09,靶向"物料第8题+action 0.116"两靶)

> 方法:对 `data_final.jsonl`(官方种子 32480 原样)与 `data_riders_fk.jsonl`(FK 转写血统)全量统计,与 17 份评测日志交叉。全程零配额。姊妹篇:`docs/action_termination_eda.md`(action 病理)。

## A. 主发现:原始数据的 think 块 = 一座被 FK 转写剥掉 65% 的 grounding 库

| 指标 | 原始官方 data_final | riders_fk(FK血统) |
|---|---|---|
| 非空 think 行 | 24,988(76.9%) | 14,595(39.2%) |
| **think 内 SID 三元组** | **138,850**(分布在 16,608 行,think 均长 1080 字) | **48,321(−65%)** |
| 答案体三元组 | 50,628 | 65,069(P3 复制答案贡献) |

- **76.2% 的 think 内三元组前 25 字符是中文语义描述**(样例:"点赞穿搭教学、美妆护肤、饰品展示类内容(<|video_begin|>…")⇒ 原始数据内嵌 **~10.6 万条 desc↔SID grounding 上下文**;
- **think 独有三元组=0**:think 不引入新 item,纯粹给历史/答案里已有的 SID 贴语义标注——**恰好是物料评测(desc→SID)考的方向**;
- **50.1% 的行处于同 prompt 重复组**(3,542 组,最大 23 变体):原始数据对同一批 item 有多样化 think 叙述=天然的多视角 grounding;FK 每组只留 1 条填充、其余掏空。

**机制闭环**:OneThree(原始数据×LoRA×1ep,平台)=物料 8 题;我方 FK 血统 5 个 LoRA 数据点清一色 7 题(对 lr×600 倍、数据 5 种全不敏感);全参 3ep 能到 8 题=从历史/答案硬啃出来的大力奇迹(交 video 税)。**"LoRA 物料墙"很可能不是容量墙也不是遍数墙,是 FK 转写把 grounding 监督剥掉了。**

**⇒ 判决实验:`seed_raw_lora_ep1`** —— data_final 原样(think 全保留)× riders 同款 LoRA(r32/α32/lr2e-4/1ep),单变量=数据(raw vs FK 重组)。预测:物料 0.2453 则机制成立;随后组合 v2 = raw 底盘 + 骑手(MC 锚/P3/world_zh,加法式,不再做任何 FK 式重组)。风险预登记:think-heavy 数据在 nothink 评测通路的表现(v1 全参×raw 无格式崩先例;rec 评测本就有 think 通路,raw 反而喂得更对)。

## B. action 侧定案(与 action_termination_eda.md 合读)

1. **100% 纯复制任务**:1588 行的全部答案项逐字来自题面 ⇒ 病在终止与选择,不在知识;
2. **k(答案条数)中位 11、p25=5、p75=19、max=56,与历史规模相关仅 0.20** ⇒ k 由主题语义决定,不能教固定条数,要教"推断 k+绝不复读+闭合即停";
3. 种子答案 21,790 项全 itemic;评测输出示例含纯文本交互("大静儿在北京")⇒ **形态缺口存疑待深查**(评测历史含 搜索-搜索 行为类型);
4. 截断题数×action 分同谱系严格反相关(qswap 5题全飞 0.031 ↔ tokengeo 1题 0.0905);平台版零截断仍 0.0675 ⇒ 会停是必要非充分。
