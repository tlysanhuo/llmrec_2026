# seed_ep3(0.8931)ad 塌因分析 — 2026-07-03

> 方法:4 路日志取证(seed_ep3-ad / recipe1-ad / baseline_sft_v1-ad / seed_ep3-live+prod)+ 独立对抗复核(关键数字全部亲验重跑)。
> 三份日志打印的 5 个 ad prompt 输入 md5 完全一致 → 跨版本严格配对比较有效。样本限制:平台每任务只打印 5/1000 个样例。

## 一、被排除的假设(全部有硬数字)

| 假设 | 结论 | 证据 |
|---|---|---|
| thinking 跨 prompt 记忆化坍缩 | **排除** | 三日志×三域:每 prompt 恰 1 条 thinking 被 32 beam 共享(机制必然);跨 5 prompt thinking 哈希 5/5 互异;此前"Output[0]/[1] thinking 一字不差"疑点=同一 prompt(Sample 0)的 beam#0/#1,已实锤 |
| 最终 SID 全局多样性坍缩 | **排除** | seed_ep3 ad 320 答案去重 230,与 recipe1(230)/v1(226)同级;top s_a 集中度(1584=22.5%)反而低于 v1(25.6%);prod 域同量级集中(2395=17.2%)却涨分 |
| 把 video SID 抄进 ad 预测 | **排除** | s_a 来源分解:seed_ep3 的 294 个抄史 s_a 全部来自本用户 ad 域历史,video_only=0;跨域前缀错误三域均为 0 |
| 1.66M 共享候选池独立致塌 | **排除(仅是放大器)** | video 同池、抄史率也高(70.9%)却得 0.1017 未塌 |
| 格式/解析问题 | **排除** | 320/320 答案行格式有效 |

## 二、坐实的塌因:**直通路(nothink beam)退化为"历史复读机",挤占候选槽位**

核心数字(5 配对 prompt × 64 候选):

| 指标 | seed_ep3(ad 0.048) | v1(ad 0.0672) | recipe1(ad 0.096) |
|---|---|---|---|
| 整句抄历史率(总) | **75.0%** | 73.8% | 71.2% |
| **直通路整句抄史** | **89.4%** | 75.6% | 78.1% |
| **直通路 s_a 抄史** | **99.4%(纯复读)** | — | — |
| 非历史新候选数 | **70(最少)** | 71 | 79 |
| 直通路新候选 | **16 个,中位 rank 28.5(垫底)** | 38 | 34 |

- 抄史率与分数**严格反向单调**(75.0/73.8/71.2 ↔ 0.048/0.067/0.096)。
- **种子数据里 ad gold 整句∈历史只有 12.6%** → 复读策略的 pass 上限天然被封死。
- **thinking 通路反而是 seed_ep3 最健康的**(62 个新候选,三模型最多)——塌的只是 nothink 直通路。
- seed_ep3 直通路 top-8 与 v1 重合 6-7/8:它就是"v1 再往历史模式压实的版本"——低 lr×3ep 没学新东西,只把数据里 ad 域最强的表面统计(gold s_a∈历史=68.3%,四域最高)复读得更死。

**live/prod 排除法通过**:同一模型同晚,live 抄史 50.9%、prod 47.8%(prod 自域历史平均 72 条却只抄 48%),显著低于 ad 的 75.6% → 高抄史是 ad 独有签名。

**根子在数据**:种子懂推荐数据 ad 域 gold s_a∈历史=68.3%(living 43%/prod 47.6%/video 39.7%)——"抄 s_a"本身是被监督信号奖励的;低 lr 多 ep 把它压实成整句照抄。

## 三、可执行含义

1. **rebal_world_ep3(在训)出分日志第一检查项**:直通路整句抄史率——≥85% 预期 ad 仍塌;回落到 ~78% 则有戏。⚠️ 无差别 ad 上采样会同时放大"抄史"监督信号,此风险已知。
2. **对症的数据侧动作(优于无差别上采样)**:ad 训练样本按"gold 是否∈输入历史"分桶——**gold∉历史的样本(教"预测新 ad")上采样/加权,gold∈历史的降权**。
3. **两阶段训练设计**:第二阶段应显式含 **nothink 格式的 ad 样本**(prompt+`<|ad_begin|>`直出答案),优先用 gold∉历史样本——因为塌的正是 nothink 直通路(现数据 76.9% 含 CoT,nothink 通路靠模板软开关泛化,低 lr 多 ep 下最先退化成复读)。
4. **向队友要 baseline-epoch3 config 时最优先核对 learning_rate**:已有 lr2e-5×3ep=0.048 塌 / lr1e-4×3ep=0.096 不塌 / lr2e-5×1ep=0.067 不塌;若队友(ad 0.0768 不塌)是 lr2e-5×3ep×cutoff8192,则 cutoff 也是变量;若是 lr1e-4,则实锤"塌因=低 lr×多 ep 交互"。
5. **机制订正**:推荐域直通路是 **beam32**(两通路 32+32=64),beam64 只在 grounding;同 Sample 内 thinking 逐字相同是机制必然。已改 memory eval-mechanism-exact。

## 置信度与遗留

- 置信度 medium:5/1000 样例抽查;v1(0.067)与 recipe1(0.096)之间 43% 的分差在这 5 个 prompt 的抄史/探索指标上几乎无差(75.6% vs 78.1%)→ 分数还依赖全量上"新候选命中质量",日志不含分值无法取证。
- 单指标警告:eval_analysis_v4 的"s_a 抄史率 0.95→0.88"已精确复现,但该单指标非单调(seed_ep3=91.9% 居中而分最低),**以后看"整句抄史率+新候选数",不看 s_a 单指标**。
