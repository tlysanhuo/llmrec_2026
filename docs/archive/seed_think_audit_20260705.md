# 种子 think 内容质量审计(2026-07-05,全量统计)

> 核心假设检验:模型线上 86-92% SID 引用保真病是否传染自训练 CoT。**结论:证伪——教材字节级干净,病因在解码侧。**

## 定案(全量数字)
1. **think 内 SID 引用保真度 = 100.0%**(懂推荐 133,516 条引用 + 懂用户 5,334 条,零变异零捏造;仅 2 条域前缀贴错=0.001%)。教师写 think 时是复制粘贴 prompt 的 SID。→ **模型的保真病是解码侧问题**(自由采样逐 token 生成 SID 无 copy 约束),与教材无关。P3 的价值定位不变(训练 copy 行为),但"清洗教材治保真"路线关闭。
2. **think 结论与 gold**:懂推荐 think 不给 gold SID(仅 0.7% 含),做的是文本画像预测(96.8% 含【预测/目标】段);域词一致 87.3%,7.9% "不一致"实为 think 截断没写到预测段,零真矛盾。
3. **种子不教复读**:同句复读 0.0%;懂用户 18.8% 同 SID 多次=合法叙事回指。复读病教源=重复上采样(已定案)。
4. **★唯一实质缺陷:7.6% 的懂推荐 think 句中夭折**(1,467 行,439 个唯一 think 经同组复制扩散;长度 p50=289 ≪ 正常 1396,系 teacher 中途夭折非撞长度墙)。答案部分完整。教坏方向:"分析写一半就闭 think"。
5. 懂物料:part1-4 的 think 是真实关键词提取(覆盖率 p50 0.50-0.65),part3/4 各 ~10-11% 元叙述废话;part5-7(SID→desc)think 为簇级泛化(覆盖率 0.05-0.11),信息量低,是剥 think 候选。
6. **截断审计:全库 0 行 >32768 token**(我们的 cutoff 安全);⚠️若走 8192 配方,懂用户 40 行(1.4%)会被截尾,须预剔。
